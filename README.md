# «Мотив» — сайт ремонта пластиковых окон в Челябинске

**Сайт:** https://denis21511.github.io/motiv/

Одностраничный сайт с 3D-калькулятором: параметры окна, 3D-модель, расчёт стоимости и форма заявки работают как одна система.

## Структура

```
index.html              страница сайта
privacy.html            политика обработки персональных данных (заполнить реквизиты)
assets/css/styles.css   стили
assets/js/site.js       собранный скрипт оформления: анимации, меню (не редактировать вручную)
assets/js/app.js        собранный скрипт 3D, калькулятора и формы (не редактировать вручную)
assets/img/             логотип, favicon, аватары для соцсетей
src/site.js             анимации, меню, мобильная плашка — грузится первым, без Three.js
src/effects.js          пиксельная планета, появление при прокрутке, пиксельные границы, счётчики
src/app.js              калькулятор, 3D, форма заявки
src/window3d.js         3D-модель окна (Three.js)
src/pricing.js          цены и формулы расчёта
scripts/build-logo.mjs  генератор SVG-логотипа
```

## Публикация

Сайт раздаётся через GitHub Pages из корня ветки `main`. Чтобы обновить сайт, достаточно собрать скрипты и отправить изменения — через 1–2 минуты они появятся по адресу выше:

```bash
npm run build
git add -A
git commit -m "Описание изменений"
git push
```

## Запуск и сборка

```bash
npm install
npm run build   # собирает src/ → assets/js/site.js и app.js
npm run watch   # пересборка при изменениях
```

Сайт статический: для публикации достаточно загрузить на хостинг `index.html`, `privacy.html` и папку `assets/`. Для локального просмотра нужен любой веб-сервер (например, `python -m http.server`), открытие файла напрямую не подойдёт — модули JS так не загружаются.

## Что заменить перед запуском

- **Телефон, часы работы, Telegram** — в `index.html` (шапка, мобильное меню, подвал, блок `ld+json`) и в `privacy.html`. Сейчас стоит заглушка `+7 (351) 000-00-00`.
- **Отзывы** — в блоке `#reviews` стоят примеры для вёрстки. Замените их реальными отзывами клиентов и поставьте ссылки на Яндекс Карты и 2ГИС.
- **Реквизиты** в `privacy.html` (помечены квадратными скобками).

## Цены и расчёт

Цены задаются в `src/pricing.js` (объект `PRICES`), после изменения — `npm run build`.

| Неисправность | Что входит в расчёт |
|---|---|
| Плохо закрывается | регулировка × число створок |
| Продувает | регулировка × створки + уплотнитель |
| Не работает ручка | 1 ручка |
| Повреждён уплотнитель | уплотнитель |
| Проблема с фурнитурой | фурнитура × число створок |
| Повреждён стеклопакет | 1 стеклопакет, площадь = ширина створки × высота |
| Комплексный ремонт | 1 500 ₽ за окно + уплотнитель |

Длина уплотнителя — периметр всех створок плюс 10 % на углы и стыки, с округлением вверх до 0,25 м. Для окна 1400 × 1400 мм с двумя створками: 9,25 м.

## Приём заявок

Пока обработчик не подключён, форма работает в демонстрационном режиме: показывает «Заявка отправлена», но данные никуда не уходят.

Чтобы заявки приходили, укажите адрес обработчика в атрибуте `data-endpoint` формы `#order-form` в `index.html`. Форма отправляет `POST` в формате `multipart/form-data`:

| Поле | Пример |
|---|---|
| `name` | Игорь |
| `phone` | +7 (912) 345-67-89 |
| `comment` | текст комментария |
| `window` | 1400 × 1400 мм |
| `sashes` | 2 |
| `problem` | Продувает |
| `estimate` | 2 850 ₽ |
| `photos[]` | до 5 изображений, до 10 МБ каждое |

Обработчик должен вернуть код 2xx. Если он вернёт ошибку или будет недоступен, форма предложит повторить отправку или позвонить.

## Оформление и анимации

Палитра — синий и голубой (переменные в начале `assets/css/styles.css`). Белые 3D-окна всегда стоят на цветном фоне: на главном экране — на синем, в калькуляторе — на сцене-чертеже.

- **Пиксельная планета** за окном на главном экране: собирается из разлетевшихся квадратов, по ней проходит световая волна, пиксели расступаются вокруг курсора. Та же планета, тёмная, — в финальном блоке. Параметры — `PixelPlanet` в `src/effects.js`.
- **Заголовок главного экрана** появляется по словам.
- **Блоки** проявляются при прокрутке (атрибуты `data-reveal` и `data-reveal-group` в разметке).
- **Пиксельные границы** между секциями (`.pixel-edge`).
- **Иконки** блока доверия прорисовываются линией, **цены** набегают счётчиком, **этапы ремонта** заполняются по шагам.
- **Карточки услуг** заливаются синим при наведении, у шапки меняется цвет при прокрутке.

При системной настройке «уменьшить движение» (prefers-reduced-motion) анимации отключаются. Если скрипты не загрузились за 3 секунды, контент показывается без анимаций.

## Логотип

Знак — сфера из квадратных пикселей с двустворчатым окном в передней части. Файлы:

- `assets/img/logo-mark.svg` — основной знак;
- `assets/img/logo-mark-inverse.svg` — для тёмного фона;
- `assets/img/favicon.svg` — иконка сайта;
- `assets/img/avatar.svg`, `avatar-navy.svg` — аватары для соцсетей.

Название «Мотив» набрано шрифтом Geologica SemiBold. Чтобы изменить знак, правьте `scripts/build-logo.mjs` и запустите `npm run logo`.
